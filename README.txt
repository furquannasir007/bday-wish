# Aeram Shamim — Birthday Surprise

A static birthday website made for Aeram Shamim.

## Run locally
Open `index.html` in a browser.

## Publish
Upload this folder to a static hosting service such as Vercel, Netlify, or GitHub Pages.
The website does not require a database or backend.

## Personalize
Open `index.html` and edit the letter/signature if you want to add your own name or private memories.
